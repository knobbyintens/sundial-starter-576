# Sundial starter

A small Jekyll starter for marketing sites. It ships with page layouts, a
navigation data file, collection folders for products, team members and news
posts, plus a GitHub Pages deployment workflow.

## Local development

```
bundle install
bundle exec jekyll serve
```

## Layout of the project

- `_layouts/` page shells
- `_includes/` navigation and footer partials
- `_data/` navigation and testimonial data
- `_products/`, `_team/`, `_posts/` collection entries
- `.github/workflows/pages.yml` publishing workflow

The theme renders out of the box because it ships with placeholder pages and
sample collection entries. Replace the sample content with your own.
